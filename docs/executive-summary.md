## 🏗 Architecture Overview

### Technology Stack
- **Frontend:** Flutter 3.x with Riverpod state management
- **Backend:** Firebase (Auth, Firestore, Functions, Storage)
- **AI:** OpenAI GPT-4 API / Google Gemini
- **Payments:** Stripe Billing
- **Infrastructure:** Firebase Hosting, Cloudflare CDN

### Domain-Driven Design
- **5 Bounded Contexts:** Identity, Practice, Mood, AI, Billing
- **Clean Architecture:** Separation of concerns, testability
- **HIPAA Compliant:** Encryption, access control, audit logging
