**At-Risk Detection:**

### 6.3 Lifetime Value (LTV) Calculation

**Assumptions:**
- ARPU: $35 (blended across tiers)
- Monthly churn: 4.5%
- Average customer lifetime: 22 months
- Gross margin: 75%

**LTV Calculation:**
```
LTV = ARPU × (1 / Churn Rate) × Gross Margin
LTV = $35 × (1 / 0.045) × 0.75
LTV = $35 × 22.2 × 0.75
LTV = $583
```

**LTV:CAC Ratio:**
- Target CAC: $150
- LTV:CAC = $583 / $150 = **3.9:1**
- **Verdict:** Healthy ratio (target is 3:1)
