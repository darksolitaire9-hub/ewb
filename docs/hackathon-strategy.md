## 📝 LLM Prompts Library

### Prompt 1: Create Base HTML
```
Create a single-page HTML application for a mood tracking app called "MoodBoard Pro". 
Include:
- Header with logo and navigation
- Main content area with tabs (Client View / Therapist View)
- Mood entry form with slider, emotion tags, and notes
- Sidebar for AI insights
- Footer with credits

Use modern CSS with a calming color scheme (blues and greens).
Make it responsive and professional-looking.
```

### Prompt 2: Add Mood Slider
```
Create a JavaScript mood slider component that:
- Ranges from 1-10
- Changes color from red (1) to green (10)
- Shows current value
- Has smooth animations
- Updates a display showing the mood level
```

### Prompt 3: Emotion Tags
```
Create emotion tag selection with:
- 8 emotions: Happy, Sad, Anxious, Angry, Calm, Tired, Excited, Depressed
- Each with an emoji
- Click to toggle selection
- Visual feedback (highlighted when selected)
- Store selected emotions in array
```

### Prompt 4: AI Integration
```
Create JavaScript code that:
1. Takes mood data (score, emotions, notes)
2. Calls OpenAI API with this prompt:
   "Analyze this mood entry and provide:
    - Brief insight (2 sentences)
    - Detected pattern (if any)
    - One recommendation"
3. Displays the AI response in a card
4. Handles errors gracefully
```

### Prompt 5: Chart Visualization
```
Using Chart.js, create a line chart that:
- Shows mood scores over time (last 7 days)
- Has a gradient fill
- Smooth curves
- Responsive design
- Tooltips on hover
```

### Prompt 6: Therapist Dashboard
```
Create a therapist dashboard view with:
- Client list (3 mock clients)
- Each client shows: name, last entry date, mood trend
- Click to view client details
- Summary statistics (average mood, total entries)
```
